Hardware

I'm a Computer Engineering student at CSULB with a focus on embedded systems and digital hardware design. I care about the layer of computing closest to the metal — where software meets silicon and timing actually matters.

My experience spans microcontroller firmware (TM4C123, ESP32), FPGA development in Verilog on the Nexys A7, and sensor interface protocols including I²C, SPI, and UART. I'm particularly interested in digital signal processing and how raw sensor data is filtered, corrected, and made useful in real-time hardware systems.

Outside the lab I work as a lead golf technician — which turns out to be surprisingly close to engineering: analyzing launch data, tuning mechanical tolerances, and diagnosing problems systematically.

01 / FPGA

FPGA-Based Digital Compass with Sensor Fusion

Real-time digital compass on the Nexys A7-100T FPGA. Designed all Verilog modules from scratch — no vendor IP — for I²C and SPI communication with a Pmod CMPS2 magnetometer and accelerometer. Implemented tilt-compensation to maintain accurate heading across off-axis orientations, with output to a seven-segment display.

All hardware description written in Verilog from first principles. Tilt compensation ensures heading accuracy across ±30° pitch and roll variation.
Verilog FPGA I²C SPI DSP Nexys A7 Sensor Fusion

02 / EMBEDDED

Line-Following Robot with FSM Controller

Led hardware design for an autonomous line-following robot using a TM4C123GH6PM microcontroller and 8-channel IR reflectance sensor array. Implemented a finite state machine for closed-loop motor control and designed a 3D-printed servo-controlled gate with IR object detection.

FSM motor control achieved consistent path tracking on a closed course. Gate servo responded to IR detection in real time.

03 / ESP32

Digital Golf GPS Range Finder

Handheld ESP32-based device with NEO-6M GPS module providing real-time yardage to the front, middle, and back of the green, current hole tracking, and hazard display. NMEA sentence parsing over UART, lightweight embedded UI, fully assembled and deployed on-course.

Deployed on a real golf course and actively used. GPS fix acquired in under 30 seconds — end-to-end product development from breadboard to enclosure.

04 / ESP32 + ANDROID

ESP32 Spotify Karaoke Display

Two-part embedded + mobile system built around real-time Spotify lyric sync. The ESP32 firmware fetches lyrics via the Spotify API, synchronizes them to the current playback position, and drives a TFT screen — all while acting as a BLE peripheral. The Android companion app (Kotlin) connects over BLE, controls playback, and hands off track metadata so the display stays in sync without polling.

Full-stack embedded system spanning firmware, a REST API integration, a custom BLE protocol, and a native Android app — built and actively developed.
ESP32 C++ Bluetooth LE Spotify API TFT Display PlatformIO Kotlin Android
